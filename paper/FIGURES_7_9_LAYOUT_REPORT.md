## Legend policy

Every legend is in a reserved strip **above**, and disjoint from, its axes
data rectangle. This replaces the previous corner-placement policy, which
could cover the hole or companion curves. Regenerated legends use 9.5-pt
type, compact line/marker tokens, two columns for the wide panel, and one
column for lower panels. The three-entry increment legend fits the common
lower strip. Panels with no legend retain the same page and axes geometry.

Retained legends preserve the original encoded glyphs, line styles, colors and
marker keys; they are scaled uniformly into the same strips. Their embedded
typeface and original wording remain, rather than claiming the unavailable
historical sources were redrawn with the new MATLAB text interpreter. All
axes decorations use the shared 11-pt label / 9.5-pt tick MATLAB LaTeX style.

## Isolated review and reproduction

From the repository root in MATLAB:

```matlab
addpath(genpath(pwd));
R = review_figures_7_9();
winopen(R.reviewPdf);                 % Windows; three assembled review pages
```

The default output directory is outside the checkout. An optional `OutputRoot`
is supported. The output includes 12 vector PDFs, PNG previews, per-panel
layout/provenance JSON, a three-page assembled vector review PDF, and
`layout_verification.json`. After inspection, promotion is limited to these
12 panels and their metadata:

```matlab
P = promote_figures_7_9_layout(R);
```

PDF handling uses Python with `pypdf`, `pdfplumber`, and `reportlab`; review
rendering uses Poppler `pdftoppm`. Set `PUBLICATION_PYTHON` and, if needed,
`PUBLICATION_PDFTOPPM` to choose installed runtimes. Missing dependencies or
changed retained sources fail explicitly. Immutable inputs are always used,
so repeated wrapping cannot accumulate scale/crop changes.
